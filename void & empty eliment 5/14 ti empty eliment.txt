এইচটিএমএল (HTML)-এ Empty Elements (যাদেরকে Void Elements বা Self-closing Elements বলা হয়) বলতে সেই সমস্ত ট্যাগগুলোকে বোঝায় যেগুলোর কোনো সমাপনী বা Closing Tag (যেমন </tag>) থাকে না এবং এদের মধ্যে কোনো কনটেন্ট/লেখা রাখার প্রয়োজন হয় না।

প্রমিত HTML5 স্পেসিফিকেশন অনুযায়ী প্রধানত ১৪টি স্ট্যান্ডার্ড Empty Element রয়েছে। নিচে এগুলোর তালিকা, কাজ ও উদাহরণসহ বিস্তারিত দেওয়া হলো:

HTML-এর প্রধান Empty Element সমূহের তালিকা ও ব্যাখ্যা
১. <br> (Line Break)
কাজ: টেক্সটের মধ্যে নতুন লাইন বা নতুন প্যারাগ্রাফ ছাড়া লাইন ব্রেক তৈরি করতে ব্যবহৃত হয়।

উদাহরণ:

HTML
<p>ঢাকা, বাংলাদেশ<br>ফোন: ০১৭০০০০০০০</p>
২. <img> (Image)
কাজ: ওয়েব পেজে ছবি বা ইমেজ যুক্ত করতে ব্যবহার করা হয়।

উদাহরণ:

HTML
<img src="photo.jpg" alt="ছবি" width="300">
৩. <input> (Input Field)
কাজ: ব্যবহারকারীর কাছ থেকে যেকোনো ডাটা বা ইনপুট (যেমন: টেক্সট, পাসওয়ার্ড, চেকসংখ্যা) নেওয়ার জন্য ব্যবহৃত হয়।

উদাহরণ:

HTML
<input type="text" placeholder="আপনার নাম লিখুন">
৪. <hr> (Horizontal Rule)
কাজ: কন্টেন্টের মধ্যে আনুভূমিক রেখা (Horizontal Line) টেনে বিষয়বস্তু ভাগ করার জন্য এটি ব্যবহার করা হয়।

উদাহরণ:

HTML
<p>প্রথম প্যারাগ্রাফ</p>
<hr>
<p>দ্বিতীয় প্যারাগ্রাফ</p>
৫. <meta> (Metadata)
কাজ: ওয়েবসাইট বা ডকুমেন্টের মেটা-তথ্য (যেমন: এনকোডিং, কি-ওয়ার্ড, ভিউপোর্ট ইত্যাদি) সার্চ ইঞ্জিন এবং ব্রাউজারকে দেওয়ার জন্য <head> ট্যাগে ব্যবহার করা হয়।

উদাহরণ:

HTML
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
৬. <link> (Link Element)
কাজ: এক্সটার্নাল কোনো ফাইলকে (যেমন: CSS ফাইল বা Favicon) HTML ডকুমেন্টের সাথে যুক্ত করতে ব্যবহার করা হয়।

উদাহরণ:

HTML
<link rel="stylesheet" href="style.css">
৭. <base> (Base URL)
কাজ: পেজের সব রিলেটিভ URL-এর জন্য একটি মূল (Base) URL নির্ধারণ করে দেয়।

উদাহরণ:

HTML
<base href="https://example.com/images/">
৮. <col> (Table Column)
কাজ: টেবিলের প্রতিটি কলামের আলাদা প্রপার্টি বা স্টাইল সেট করতে ব্যবহৃত হয় (সাধারণত <colgroup>-এর ভেতরে থাকে)।

উদাহরণ:

HTML
<col span="2" style="background-color:red">
৯. <embed> (Embed Content)
কাজ: অন্য কোনো অ্যাপ্লিকেশন বা ইন্টারেক্টিভ কন্টেন্ট (যেমন: মিডিয়া প্লেয়ার, PDF) পেজে যুক্ত করতে এটি ব্যবহৃত হয়।

উদাহরণ:

HTML
<embed type="video/mp4" src="video.mp4" width="300" height="200">
১০. <source> (Media Source)
কাজ: <video> বা <audio> ট্যাগের মধ্যে একাধিক মিডিয়া ফাইলের উৎস বা সোর্স নির্দেশ করতে এটি ব্যবহার করা হয়।

উদাহরণ:

HTML
<audio controls>
  <source src="song.mp3" type="audio/mpeg">
</audio>
১১. <track> (Text Track)
কাজ: ভিডিও বা অডিও কন্টেন্টের সাথে সাবটাইটেল বা ক্যাপশন ফাইল যুক্ত করতে ব্যবহার করা হয়।

উদাহরণ:

HTML
<video src="video.mp4">
  <track src="subtitles_en.vtt" kind="subtitles" srclang="en" label="English">
</video>
১২. <wbr> (Word Break Opportunity)
কাজ: দীর্ঘ কোনো শব্দের কোথায় লাইন ব্রেক করা নিরাপদ তা ব্রাউজারকে নির্দেশ করতে ব্যবহার করা হয়।

উদাহরণ:

HTML
<p>ThisIsAVeryLongWord<wbr>ThatMightBreak.com</p>
১৩. <area> (Image Map Area)
কাজ: একটি ইমেজের ভেতরের কোনো নির্দিষ্ট অংশকে ক্লিকেবল লিংকে রূপান্তর করতে ব্যবহৃত হয় (সাধারণত <map> ট্যাগের ভেতরে)।

উদাহরণ:

HTML
<area shape="rect" coords="0,0,82,126" href="sun.html" alt="Sun">
১৪. <param> (Parameter)
কাজ: <object> ট্যাগে থাকা প্লাগইন বা কোনো অ্যাপ্লেটের জন্য প্যারামিটার সংজ্ঞায়িত করতে ব্যবহৃত হয়।

উদাহরণ:

HTML
<object data="flashfile.swf">
  <param name="autoplay" value="true">
</object>
সংক্ষিপ্ত টিপস:

HTML5-এ এই ট্যাগগুলোতে /> লেখা আবশ্যক নয় (যেমন: <img src="..."> ই যথেষ্ট)। তবে XHTML বা React/JSX-এ কোড করার সময় এগুলোকে বাধ্যতামুলকভাবে <img src="..." /> এভাবে ক্লোজ করতে হয়।
