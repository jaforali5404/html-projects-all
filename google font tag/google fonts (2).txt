হ্যাঁ, একদম করা যায়!

আপনি যদি পুরো পেজে ফন্টটি না দিয়ে নির্দিষ্ট কোনো লেখা বা সেকশনে ব্যবহার করতে চান, তবে body ট্যাগে ফন্ট না দিয়ে একটি CSS Class (ক্লাস) তৈরি করে কেবল সেই নির্দিষ্ট জায়গায় প্রয়োগ করতে হবে।

কীভাবে করবেন (সহজ সমাধান):
HTML
<html>
  <head>
    <meta charset="utf-8">
    <!-- ১. ফন্ট আগের মতোই head-এ লিংক থাকবে -->
    <link rel="stylesheet" href="https://fonts.googleapis.com/css?family=Tangerine">
    
    <style>
      /* ২. একটি কাস্টম ক্লাস তৈরি করুন */
      .fancy-text {
        font-family: 'Tangerine', serif;
        font-size: 48px;
      }
    </style>
  </head>
  <body>

    <!-- সাধারণ লেখা (যেখানে এই ফন্ট কাজ করবে না) -->
    <p>এটি সাধারণ ফন্টে দেখাবে।</p>

    <!-- ৩. নির্দিষ্ট জায়গায় class="fancy-text" বসিয়ে দিন -->
    <div class="fancy-text">Making the Web Beautiful!</div>

    <!-- অন্য আরেকটি সাধারণ লেখা -->
    <p>এটিও সাধারণ ফন্টেই থাকবে।</p>

  </body>
</html>
এখানে কী পরিবর্তন করা হলো?
১. body তুলে দিয়ে .fancy-text নাম দেওয়া হয়েছে: body এর বদলে একটি ক্লাসের নাম (যেমন: .fancy-text) ব্যবহার করা হয়েছে, যাতে এটি পুরো পেজে ভুলবশত অ্যাপ্লাই না হয়ে যায়।
২. HTML-এ class="" যোগ করা হয়েছে: আপনি যে <div>, <p> বা <h1>-এ এই ফন্টটি দেখাতে চান, কেবল সেটিতে class="fancy-text" লিখে দিলেই শুধু ওইটুকু লেখাই Tangerine ফন্টে বদলে যাবে!

হ্যাঁ, একদম পারবেন!

বরং বাস্তব জীবনে বেশিরভাগ ওয়েব ডেভেলপারই নিজেরা ফন্ট তৈরি না করে Google Fonts থেকেই কপি-পেস্ট করে ব্যবহার করেন।

নিজের ফন্ট তৈরি করা অনেক কঠিন এবং সময়সাপেক্ষ কাজ। তাই গুগলের তৈরি করা হাজার হাজার তৈরি ফন্ট থেকে ফ্রিতে কপি করে নেওয়াটাই সবচেয়ে সহজ ও নিয়মমাফিজ পদ্ধতি।

গুগল ফন্ট থেকে ফন্ট নেয়ার সহজ ৪টি ধাপ:
১. গুগল ফন্টে যান: প্রথমে fonts.google.com ওয়েবসাইটে ঢুকুন।
২. ফন্ট পছন্দ করুন: আপনার পছন্দের যেকোনো ফন্টের ওপর ক্লিক করুন (যেমন: Poppins বা Roboto)।
৩. ফন্ট সিলেক্ট করুন: আপনার যে সাইজ বা স্টাইলটি পছন্দ (যেমন: Regular 400 বা Bold 700), তার পাশে থাকা + Get font বা Get embed code বাটনে ক্লিক করুন।
৪. কোড কপি করুন: গুগল আপনাকে দুটি কোড দেবে:

HTML Code: এটি কপি করে আপনার HTML ফাইলের <head> ট্যাগের ভেতরে বসিয়ে দেবেন।

CSS Code: এটি কপি করে আপনার CSS স্টাইলে font-family হিসেবে ব্যবহার করবেন।

সংক্ষেপে:
আপনাকে নিজে কষ্ট করে ফন্ট বানাতে হবে না। গুগল আপনাকে কোড রেডি করেই দেয়, আপনার কাজ শুধু সেটা কপি করে এনে আপনার ওয়েবসাইটে পেস্ট করে দেওয়া!
