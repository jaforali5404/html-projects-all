📌 টেবিল ট্যাগসমূহের তালিকা ও ব্যাখ্যাট্যাগ (Tag)বিবরণ / কাজ<table>টেবিল তৈরি করার প্রধান কন্টেইনার ট্যাগ। সকল টেবিল এলিমেন্ট এর ভেতরে থাকে।
<caption>টেবিলের শিরোনাম বা ক্যাপশন নির্দেশ করে (সাধারণত টেবিলের একদম উপরে দেখায়)।
<thead>টেবিলের হেডার অংশকে (Header Section) একটি গ্রুপ হিসেবে প্রকাশ করে।
<tbody>টেবিলের মূল তথ্য বা বডি অংশকে (Body Section) গ্রুপ করে।
<tfoot>টেবিলের নিচের বা ফুটার অংশকে (Footer Section - যেমন: মোট হিসাব) গ্রুপ করে।
<tr>(Table Row) টেবিলের প্রতিটি সারি তৈরি করে।
<th>(Table Header) হেডার বা শিরোনামের সেল তৈরি করে (লেখা গাঢ় ও সেন্টারে থাকে)।
<td>(Table Data) সাধারণ ডেটা বা তথ্যের সেল তৈরি করে।
<colgroup>এক বা একাধিক কলামকে একত্রে স্টাইল দেওয়ার জন্য গ্রুপ হিসেবে তৈরি করে।
<col><colgroup> এর ভেতরে নির্দিষ্ট কলামের স্টাইল বা উইডথ নির্ধারণ করে।
💻 সম্পূর্ণ কোড উদাহরণ (All-in-One Example)নিচে একটি উদাহরণ দেওয়া হলো যেখানে সবকটি টেবিল ট্যাগ একসঙ্গে ব্যবহার করা হয়েছে:HTML
<!DOCTYPE html>
<html lang="bn">
<head>
  <meta charset="UTF-8">
  <title>HTML Table Example</title>
  <style>
    table {
      width: 80%;
      border-collapse: collapse;
      margin: 20px auto;
      font-family: Arial, sans-serif;
    }
    th, td {
      border: 1px solid #ddd;
      padding: 10px;
      text-align: center;
    }
    caption {
      font-size: 1.3em;
      font-weight: bold;
      margin-bottom: 10px;
    }
  </style>
</head>
<body>

  <!-- ১. <table>: প্রধান কন্টেইনার -->
  <table>

    <!-- ২. <caption>: টেবিলের ক্যাপশন -->
    <caption>বার্ষিক পরীক্ষার ফলাফল ও ফি বিবরণী</caption>

    <!-- ৩. <colgroup> ও ৪. <col>: কলামের স্টাইলিং -->
    <colgroup>
      <col style="background-color: #f2f2f2;"> <!-- ১ম কলাম -->
      <col style="background-color: #ffffff;"> <!-- ২য় কলাম -->
      <col style="background-color: #e6f7ff;"> <!-- ৩য় কলাম -->
    </colgroup>

    <!-- ৫. <thead>: টেবিলের হেডার -->
    <thead>
      <!-- ৬. <tr>: সারি -->
      <tr>
        <!-- ৭. <th>: হেডার সেল -->
        <th>রোল</th>
        <th>শিক্ষার্থীর নাম</th>
        <th>পরীক্ষার ফি (টাকা)</th>
      </tr>
    </thead>

    <!-- ৮. <tbody>: মূল ডেটা সেকশন -->
    <tbody>
      <tr>
        <!-- ৯. <td>: ডেটা সেল -->
        <td>১০১</td>
        <td>রাহিম আহমেদ</td>
        <td>৫০০</td>
      </tr>
      <tr>
        <td>১০২</td>
        <td>সাদিয়া সুলতানা</td>
        <td>৫০০</td>
      </tr>
      <tr>
        <td>১০৩</td>
        <td>করিম হাসান</td>
        <td>৫০০</td>
      </tr>
    </tbody>

    <!-- ১০. <tfoot>: টেবিল ফুটার -->
    <tfoot>
      <tr>
        <th colspan="2">সর্বমোট ফি</th>
        <th>১৫০০</th>
      </tr>
    </tfoot>

  </table>

</body>
</html>
💡 দুটি গুরুত্বপূর্ণ অট্রিবিউট (Bonus Attributes)টেবিলের সেলগুলোকে যুক্ত (Merge) করার জন্য দুটি বিশেষ অট্রিবিউট প্রচুর ব্যবহৃত হয়:colspan: একাধিক কলামকে আনুভূমিকভাবে (Horizontally) একসাথে যুক্ত করতে ব্যবহৃত হয়।উদাহরণ: <th colspan="2"> (২টি কলামকে একসাথে মেলাবে)।rowspan: একাধিক সারিকে উলম্বভাবে (Vertically) একসাথে যুক্ত করতে ব্যবহৃত হয়।উদাহরণ: <td rowspan="3"> (৩টি সারিকে একসাথে মেলাবে)।

HTML-এর প্রতিটি টেবিল ট্যাগের কাজ এবং একটি করে ছোট কোড উদাহরণ নিচে দেওয়া হলো:

১. <table> ট্যাগ
কাজ: টেবিল তৈরির প্রধান কন্টেইনার।

উদাহরণ:

HTML
<table>...</table>
২. <caption> ট্যাগ
কাজ: টেবিলের শিরোনাম দেখায়।

উদাহরণ:

HTML
<caption>দৈনিক জমা: ১,০০০ টাকা</caption>
৩. <thead> ট্যাগ
কাজ: টেবিলের উপরের হেডার অংশ গ্রুপ করে।

উদাহরণ:

HTML
<thead>
  <tr><th>নাম</th><th>টাকা</th></tr>
</thead>
৪. <tbody> ট্যাগ
কাজ: টেবিলের মূল তথ্য বা ডেটা অংশ গ্রুপ করে।

উদাহরণ:

HTML
<tbody>
  <tr><td>রহিম</td><td>৫০০</td></tr>
</tbody>
৫. <tfoot> ট্যাগ
কাজ: টেবিলের নিচের ফুটার বা মোট হিসাবের অংশ গ্রুপ করে।

উদাহরণ:

HTML
<tfoot>
  <tr><td>মোট</td><td>৫০০</td></tr>
</tfoot>
৬. <tr> ট্যাগ
কাজ: টেবিলের একটি সারি (Row) তৈরি করে।

উদাহরণ:

HTML
<tr>
  <td>ডেটা</td>
</tr>
৭. <th> ট্যাগ
কাজ: টেবিলের কলামের শিরোনাম (Header Cell) তৈরি করে (লেখা বোল্ড থাকে)।

উদাহরণ:

HTML
<th>মূল্য (টাকা)</th>
৮. <td> ট্যাগ
কাজ: টেবিলের সাধারণ তথ্য/ডেটা (Data Cell) ধারণ করে।

উদাহরণ:

HTML
<td>২৫০ টাকা</td>
৯. <colgroup> ও <col> ট্যাগ
কাজ: এক বা একাধিক কলামের জন্য স্টাইল (যেমন: ব্যাকগ্রাউন্ড কালার) একসাথে সেট করে।

উদাহরণ:

HTML
<colgroup>
  <col style="background-color: yellow;">
</colgroup>



******
১. Table Align (<table align="...">)
কাজ: পুরো টেবিলটিকে পেজের বামে (left), ডানে (right) অথবা মাঝখানে (center) বসাতে ব্যবহার করা হয়।

উদাহরণ:

HTML
<table align="center">
  <!-- পুরো টেবিলটি পেজের মাঝখানে থাকবে -->
</table>
২. TR Align (<tr align="...">)
কাজ: একটি নির্দিষ্ট সারির (Row) ভেতরের সব লেখার এলাইনমেন্ট একসাথে নির্ধারণ করে (left, center, right)।

উদাহরণ:

HTML
<tr align="center">
  <td>এই রো-এর সব লেখা</td>
  <td>মাঝখানে থাকবে</td>
</tr>
৩. TD Align (<td align="...">)
কাজ: টেবিলের কোনো একটি নির্দিষ্ট সাধারণ ঘরের (Data Cell) টেক্সটকে ডানে, বামে বা মাঝে সাজাতে ব্যবহৃত হয়।

উদাহরণ:

HTML
<td align="right">৳ ৫০০.০০</td>
৪. TH Align (<th align="...">)
কাজ: টেবিলের শিরোনামের ঘরের (Header Cell) লেখা সাধারণত মাঝখানে থাকে, এটি দিয়ে তা পরিবর্তন করে ডানে বা বামে নেওয়া যায়।

উদাহরণ:

HTML
<th align="left">পণ্যের নাম</th>
৫. Background Color (bgcolor="...")
কাজ: পুরো টেবিল, কোনো নির্দিষ্ট সারি (<tr>) বা কোনো ঘরের (<td>/<th>) পেছনের ব্যাকগ্রাউন্ড কালার সেট করতে ব্যবহার করা হয়।

উদাহরণ:

HTML
<tr bgcolor="yellow">
  <td bgcolor="lightblue">হলুদ ও হালকা নীল ব্যাকগ্রাউন্ড</td>
</tr>
৬. Border (border="...")
কাজ: টেবিল এবং তার ভেতরের ঘরগুলোর চারপাশের বর্ডারের বা সীমানার পুরুত্ব (Pixel) নির্ধারণ করে।

উদাহরণ:

HTML
<table border="2">
  <!-- ২ পিক্সেল পুরু বর্ডার তৈরি হবে -->
</table>
৭. Frame (frame="...")
কাজ: টেবিলের বাইরের চারপাশের সীমান্ত বা ফ্রেমের কোন দিকগুলো দেখা যাবে তা নিয়ন্ত্রণ করে (যেমন: box, above, below, hsides, vsides)।

উদাহরণ:

HTML
<table border="1" frame="hsides">
  <!-- শুধু ওপর ও নিচের বাইরের ফ্রেম দেখা যাবে -->
</table>
৮. Rules (rules="...")
কাজ: টেবিলের ভেতরের ঘরগুলোর ভেতরের বর্ডার বা দাগগুলো কীভাবে দেখাবে তা ঠিক করে (যেমন: all, rows, cols, none)।

উদাহরণ:

HTML
<table border="1" rules="rows">
  <!-- শুধু সারিগুলোর (Rows) ভেতরের দাগ দেখাবে -->
</table>
৯. Width (width="...")
কাজ: পুরো টেবিল বা কোনো নির্দিষ্ট কলামের চওড়া বা প্রস্থ (Pixel বা Percentage-এ) নির্ধারণ করে।

উদাহরণ:

HTML
<table width="100%">
  <tr>
    <td width="50%">এই ঘরটি অর্ধেক জায়গা নেবে</td>
  </tr>
</table>
